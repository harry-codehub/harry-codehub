##  Software / Systems / Test Engineer - AI Consultant

Software, systems, and test engineer with decades of experience across medical devices, defense/aerospace, simulation, and test automation. Since 2024, working part-time as an AI Consultant focused on model evaluation, prompt testing, data quality, and applying engineering discipline to AI systems. Strong background in requirements analysis, structured testing, defect detection, verification and validation, and process improvement, working in Python, C++, C, Java, SQL, MATLAB, and R across client-server, distributed, and real-time systems.

Design and execute prompt test suites that assess model accuracy, consistency, instruction-following, safety, and edge-case behavior. Evaluate model outputs against rubrics, guidelines, and reference answers, documenting hallucinations, bias, omissions, and reasoning errors. Run regression checks across AI tools and model versions, review and quality-check training and evaluation data, and build repeatable evaluation checklists and lightweight Python and SQL automation to streamline prompt testing and data review.

Maintained continuity of mission-critical testing as a Systems Test Engineer over a 35-year tenure, leading the transition of Litton testing platforms from PDP computers to PC-based systems and spending the final decade automating the testing process to reduce manual effort and improve repeatability. Went on to support requirements definition, system design, and verification for regulated medical device development, and built an automated sanity check for a small team producing weekly builds. Since 2015, providing independent software engineering consulting across development, systems engineering, testing, and automation.
